# Parameter files

`load_params(path)` reads one top-level TOML table per scalar parameter and returns
`(values=..., provenance=...)`. `values` is a `NamedTuple`; `provenance` is a vector
of named rows with columns `name`, `units`, `source`, `location`, `notes`, and
`confidence`. Both are sorted alphabetically by parameter name.

```julia
using FermentModels

values, provenance = load_params("params/template.toml")
ismissing(values.lab_mu_max) # true: the template has no measured values
```

Each parameter uses these fields; unknown fields are rejected to catch typos.

| Field | Requirement |
|---|---|
| `value` | Finite scalar number; booleans are rejected. For an unavailable placeholder, omit it or use the string `"missing"`. |
| `units` | Nonblank string, including for placeholders. Use `"1"` for dimensionless quantities. |
| `source` | Nonblank citation, such as a DOI, or a reference to the fit script. May be omitted for placeholders. |
| `location` | Nonblank table, figure, equation, or fit-output reference. May be omitted for placeholders. |
| `notes` | Optional string. A missing value requires a `TODO` note. Record organism, conditions, population basis, and fit dataset here as applicable. |
| `confidence` | Exactly `"high"`, `"medium"`, `"low"`, or `"placeholder"`. |

TOML has no native missing value. The loader converts an omitted `value` or the
exact string `"missing"` to Julia's `missing` only when confidence is `placeholder`
and the notes contain `TODO`. Omitted placeholder source and location fields also
become `missing` in the provenance rows. Numeric placeholders are accepted by the
loader with their confidence tag preserved, as allowed by the plan; repository
parameters still require the evidence specified in [the agent rules](../docs/AGENTS.md).

The loader preserves numeric types, metadata text, and source units. It validates
the file structure, not the scientific evidence or unit meanings. Convert source
units to the project's internal units at the model-loading boundary before
passing values to an RHS function. Fitted values must identify both the fitting
script and its dataset. The three `cocoa_*_scaled.toml` files contain published
posterior means from supplement Tables S4-S6, generated by
`scripts/prepare_cocoa.jl`. They use normalized state coordinates; see
[the cocoa coordinate conventions](../docs/cocoa_baseline.md) before use.
[template.toml](template.toml) still contains an unresolved placeholder.
